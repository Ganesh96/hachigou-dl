# Interview OS

This directory is the external memory for interview preparation, technical learning, and decision-pattern correction.

The goal is not to collect notes. The goal is to preserve reusable judgment: concepts, mistakes, corrected explanations, drills, and interview-grade phrasing.

## Operating rule

Each concept is learned through this loop:

1. What problem does it solve?
2. What is the mechanism?
3. What are the preconditions?
4. What tradeoffs does it introduce?
5. Where does it fail?
6. How would I explain it in an interview?
7. What small problem can I solve with it?

## Learning style

Prefer containment over willpower, structure over motivation, and decision elimination over optimization.

A good note should answer: what changed in my future behavior because I learned this?
